# Todo100 — веб-редактор

Локальный редактор категорий / задач / заметок для базы `todo100-5db8c` (Firebase RTDB).
Работает в браузере, без бэкенда. Пишет данные прямо в Firebase или экспортирует/импортирует JSON-файл.

## Файлы
- `index.html` — само приложение (всё в одном файле)
- `start.command` — запуск в один клик (macOS)
- `README.md` — этот файл

---

## Запуск

### Вариант 1 — в один клик (macOS)
Дважды кликни по `start.command`.
Откроется терминал с локальным сервером и браузер на http://localhost:8777
(первый раз macOS может спросить разрешение: ПКМ → «Открыть»).

Остановить — закрыть окно терминала или Ctrl+C.

### Вариант 2 — вручную (любая ОС)
В терминале:
```bash
cd путь/к/editor
python3 -m http.server 8777
```
Открыть в браузере: http://localhost:8777

> Можно открыть `index.html` двойным кликом (file://) — но через локальный
> сервер надёжнее (Firebase Auth и ES-модули работают предсказуемо).

---

## Как пользоваться

1. **Firebase…** — config компании уже зашит, вводишь только **email/пароль**
   (тот же аккаунт, что в приложении) → **Войти**. UID подставится сам.
2. **Загрузить из Firebase** — читает `users/{uid}/backup` и показывает 4 списка.
3. Редактируешь:
   - **+ Категория** / переименовать / **Удалить** / двигать ↑↓, тумблер `daily`
   - **+ Задача / заметка**: текст (многострочный), галочка done, приоритет,
     цикличность, ↑↓, ✕; «ещё поля» — count/max/накопл./sectionId/position
4. **Сохранить в Firebase** — записывает обратно (с подтверждением).

### Подстраховка без Firebase
- **Скачать JSON** — выгрузить текущее состояние в файл формата экспорта.
- **Загрузить файл** — открыть ранее скачанный JSON для правки.

Рекомендация для первого раза: правишь → **Скачать JSON** и проверяешь файл,
и только потом **Сохранить в Firebase**.

## Важно
- **Сохранение перезаписывает весь `backup`** целиком (с подтверждением). Если
  правил с одного устройства, а параллельно менял с телефона — последняя запись победит.
- Одна и та же задача может лежать в нескольких папках (механика `extraFolderIds`).
  Редактор правит **каждую копию отдельно** — синхронизации между копиями нет.
- `databaseURL` указывает на регион **europe-west1** — это нормально, так и надо.
- `apiKey` Firebase лежит в `index.html` открыто. Для web-приложения это не секрет
  (доступ ограничивают Security Rules), но не публикуй файл в открытых репозиториях без нужды.
